# Distinguished contract, publishing, and decision layers

The learner can now distinguish an OpenAPI contract from backend implementation, identify Docusaurus as the documentation organisation and publishing layer, and explain that an ADR preserves the context, alternatives, consequences, and reversal conditions behind a framework decision. This establishes the boundary vocabulary needed for framework selection and later API Reference engineering lessons.

## Evidence

After targeted feedback, the learner correctly explained the externally observable API contract, separated API facts from the Docusaurus build layer, and described how an ADR supports future re-evaluation when requirements change.
