# Technical Writing Fundamentals

An eight-week public documentation-engineering lab for a minimal vector-search API and Python SDK.

## What this demonstrates

- Developer-documentation information architecture using Diátaxis as a decision aid.
- Traceable REST and Python SDK API reference material.
- Docs-as-code quality automation and a documented improvement loop.
